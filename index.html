01 / OVERVIEW

项目概览

从矢量共轴动力单元出发，面向高机动空中机器人，探索动力执行、实时通信与智能交互的系统级集成。

PROJECT CORE

矢量共轴动力系统

采用上下双旋翼共轴布局，结合矢量调节机构，探索旋翼动力输出与推力方向调节的协同控制。动力单元通过 EtherCAT 架构接入整机控制系统。

PROJECT DIRECTION

智能空中机器人

在已完成的动力单元、机载硬件架构和驱动板卡基础上，后续引入 RDK S600 NPU，开展动态目标感知、运动预测及机械臂交互任务。

03 / HARDWARE DESIGN

硬件设计与已完成工作

项目当前成果集中在动力单元本体、整机机载硬件布局，以及配套驱动 PCB 板卡开发。

01 — POWERTRAIN

矢量共轴动力单元设计

完成矢量共轴动力单元设计，围绕上下共轴旋翼、矢量调节机构与动力执行模块开展结构集成，为整机动力输出与推力方向调节提供基础。

共轴旋翼布局矢量调节机构模块化设计
02 — AIRFRAME

机载硬件架构设计

完成空中机器人整体硬件架构设计，采用左右双动力模块对称布局，通过直线圆柱机臂连接中央机身，并规划机载计算、传感器与执行模块的集成位置。

左右对称布局中央机身机械臂扩展
03 — DRIVER PCB

动力单元 PCB 驱动板卡

完成动力单元配套驱动板卡开发，围绕动力执行机构进行控制电路与通信接口设计，为动力单元控制及后续 EtherCAT 系统集成提供硬件基础。

驱动板卡控制接口通信接口
04 — EDGE AI / PLANNED

端侧 AI 与竞技任务

计划基于地平线 RDK S600 NPU 开展动态目标检测、连续跟踪与运动预测，并结合下方机械臂探索空中击球和精准抓取。

RDK S600动态目标感知空中交互

06 / APPLICATION VISION

未来应用方向

基于同一套动力与控制平台，逐步扩展不同类型的空中机器人任务。

◎

↗
